Instruction:

  • Enter needed fields in Settings tab
  • Enter observation data in Input tab; each row can contain a value in the following format:
    • Time in format HHMM
    • For field of obstruction enter a percent (e.g. 20%)
    • LM (Limiting magnitude) (e.g. Lm=6.1)
    • Dec (Declination in degrees) (e.g. Dec=35)
    • RA (Right Ascension in degrees) (e.g. RA=275)
    • Meteor magnitude from -6 to 7
      • For sporadic add minus at end (e.g. 3-)
      • For minor shower add meteor code of the shower at the end (e.g. 3CAP) @if (showers) { from list of minor showers in settings: {{ showers }} }
    • For observation break enter two slashes (//)
  • Download the calculated tabs in CSV format:
    select Count Distribution tab, export as CSV;
    select Magnitude Distribution tab, export as CSV;
  • Navigate to IMO upload observation and follow instructions to upload the two downloaded CSV files

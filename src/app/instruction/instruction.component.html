Quick Guide
  • Enter needed fields in Settings tab
  • Enter observation data in Input tab; each row can contain a value in the following format:
    • HHMM — Time
    • 20% — Field of obstruction
    • Lm=6.1 — Limiting magnitude
    • Dec=35 — Declination (degrees)
    • RA=275 — Right Ascension (degrees)
    • -6 to 7 — Meteor magnitude
      • 3- — sporadic (add minus at end)
      • 3CAP — minor shower (add code at end) @if (showers) { Active: {{ showers }} }
    • // — Observation break
  • Export CSV from Count and Magnitude tabs
  • Upload to IMO upload observation
